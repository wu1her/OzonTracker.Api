# ВПКС — лабораторная работа № 3

**Тема:** проектирование архитектуры и базы данных программной системы Ozon Tracker.

[Отчёт Word](ВПКС_ЛР3_OzonTracker.docx)

Титульный лист и оформление основаны на предоставленной ЛР1: Земсков В.В., группа 4438, преподаватель Шумилкин А.О.; A4, Times New Roman 14, межстрочный интервал 1,5, поля 30/15/20/20 мм. Таблицы оформлены шрифтом 12 пт, как в образце.

В отчёт включены:

- Выбор трёхуровневой архитектуры и сравнение с альтернативами.
- Архитектурная схема с компонентами и протоколами.
- Описание всех десяти таблиц, типов атрибутов и ключей.
- ER-модель в нотации «воронья лапка», разделённая на четыре читаемых представления с полным составом атрибутов.
- Связи и их обязательность, составные внешние ключи и реализация M:N.
- Разбор нормализации и отдельная таблица доказательства 3НФ для каждого отношения.
- Ответы на все 40 вопросов из задания, включая повторяющиеся формулировки, и вывод.

Схема сверена с `Database/setup.sql`, `Database/accounts.sql` и `Database/profile.sql`. Старые `UserProfiles` и `ChatMessages` показаны как таблицы совместимости. Работа описывает текущую демонстрационную реализацию с SQL Server; интеграция с Ozon API не заявлена. Код приложения и схема БД не изменялись.

Все рисунки уже вставлены в DOCX. В [diagrams](diagrams) находятся PNG и редактируемые SVG, в [schema.json](schema.json) — состав атрибутов диаграмм. Скриншоты добавлять не нужно.
