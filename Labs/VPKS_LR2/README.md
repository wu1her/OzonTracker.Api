# ВПКС — лабораторная работа № 2

**Тема:** разработка диаграмм активности, состояний и последовательностей для моделирования поведения системы Ozon Tracker.

[Скачать отчёт Word](ВПКС_ЛР2_OzonTracker.docx)

Титульный лист, стили, поля и оформление заимствованы из предоставленного отчёта ЛР1. Сохранены данные: Земсков В.В., группа 4438, преподаватель Шумилкин А.О.

В отчёт включены:

- Три таблицы сценариев и три диаграммы деятельности: добавление товара, просмотр статистики, удаление из отслеживания.
- Три таблицы переходов и три диаграммы состояний: личное отслеживание, наличие товара, пороговое правило цены.
- Таблица участников и три диаграммы последовательностей для выбранных сценариев.
- Ответы на все 36 контрольных вопросов и вывод.

Модель ЛР1 уточнена по текущей реализации проекта: SQL Server, демонстрационные данные, разделение по аккаунтам, сохранение истории при прекращении отслеживания. Реальное подключение Ozon API не заявлено.

Диаграммы уже вставлены в DOCX: дополнительные скриншоты не нужны. В каталоге [diagrams](diagrams) находятся отдельные PNG и редактируемые SVG. Для двух схем также приложены исходники Graphviz DOT. PlantUML не используется.
