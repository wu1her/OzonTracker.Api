## Лабораторная работа № 6 — «Тёмная и светлая темы»

Отчёт подготовлен для проекта Ozon Tracker по предоставленному образцу.

- [Отчёт Word — для заполнения](Lab6/OzonTracker_Lab6.docx)
- [Отчёт PDF — для просмотра](Lab6/OzonTracker_Lab6.pdf)

В отчёте оставлены восемь мест для изображений с подписями. Заполните ФИО и группу на титульном листе, проверьте данные учебного заведения и преподавателя, затем вставьте свои скриншоты по инструкции.

Чтобы скачать документ на GitHub, откройте соответствующий файл и нажмите **Download raw file** (значок скачивания). Также можно скачать весь проект: **Code → Download ZIP**, предварительно выбрав ветку **beta**.
